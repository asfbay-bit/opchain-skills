# Question bank: delivery mode

For discovery on work already signed. Each question fills one field of the intake record, so coverage can be scored afterwards. The default priority is a starting point: prep raises or lowers it from what the attached material (the signed scope, earlier intake records) already answers, and keeps at most three must-asks per block. There is no budget question: the work is already priced.

| Field | Block | Default | Good to send ahead |
|---|---|---|---|
| `trigger` | Open (0–2) | must-ask | no |
| `current_process` | Problem (2–8) | must-ask | no |
| `owners` | Problem (2–8) | must-ask | yes |
| `pain` | Problem (2–8) | must-ask | no |
| `volume` | Problem (2–8) | if-time | yes |
| `systems` | Systems (8–13) | must-ask | yes |
| `data_condition` | Systems (8–13) | must-ask | no |
| `regime` | Systems (8–13) | must-ask | no |
| `data_records` | Systems (8–13) | if-time | yes |
| `success` | Success (13–17) | must-ask | no |
| `timeline` | Success (13–17) | must-ask | no |
| `decision` | Success (13–17) | must-ask | yes |
| `fit_risks` | Success (13–17) | if-time | no |
| `next_step` | Read back (17–20) | must-ask | no |

Eleven must-asks by default.

## trigger
"What kicked off this project internally?"

## current_process
"Walk me through the last time this happened, start to finish. Where does it start, and where is it really finished?"
- If vague: "What was the very first thing someone did? And the last?"

## owners
"For each step: who does it, and who checks it?"

## pain
"Which step fails most? What does a bad week look like?"
- If vague: "When was the last bad week, and what went wrong?"

## volume
"How many per week, and what's the peak?"

## systems
"Which systems hold the record? Where do people copy and paste?"

## data_condition
"Is the data clean, or does someone fix it by hand? Is anything sensitive in it?"

## regime
"Is there any rule or audit this has to satisfy?"
- One plain question. A clear "no" removes all compliance wording from everything written for this client.

## data_records
"What has to be kept, for how long, and who asks for it?"

## success
"How will you know it's working in the first month?"

## timeline
"What's fixed and what can move?"

## decision
"Who signs off each deliverable?"

## fit_risks
"What's been tried, and why did it stop?"

## next_step
Agree the next session and who must attend.
